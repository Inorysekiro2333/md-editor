md-editor

A free, open-source, WYSIWYG Markdown editor that feels like Typora.

Single-pane live rendering, zero round-trip loss, and silent PDF export — on Windows, macOS, and Linux.

Download View on GitHub

WYSIWYG Editing

Type Markdown and see the rendered result instantly in a single pane. Switch to raw source mode at any time with Ctrl+/ — content and cursor position are preserved.

Theme System

Built-in GitHub Light, GitHub Dark, and Paper Serif themes. Your choice persists across sessions and applies to everything, including exports.

Export

Export to print-ready PDF (powered by Electron printToPDF) or a fully self-contained HTML file — styles inlined, images embedded, one shortcut away.
