# 使用指南

欢迎使用 md-editor。这是一份中文长文档，用于验证中文内容在编辑内核中的往返保真。

## 快速上手

打开应用后，你会看到一个干净的单栏编辑界面。直接输入文字，标题、列表和表格会实时渲染，无需手动刷新预览。

* 输入 `# 加空格` 创建一级标题。
* 输入 `- 加空格` 创建无序列表。
* 输入 `1. 加空格` 创建有序列表。
* 输入 `> 加空格` 创建引用。

## 写作建议

1. 先列大纲，再填内容。
   * 大纲用二三级标题组织。
   * 每节控制在三百字以内。
2. 善用引用块摘录资料。
   > 引用内容会保持原样保存，序列化时不改动措辞。
3. 代码示例放在围栏代码块中。

```ts
function 问候(名字: string): string {
  return `你好，${名字}！`
}
```

## 常见问题

### 中文标点会被改动吗

不会。句号、逗号、书名号等标点在往返中保持原样。

### 表格支持哪些语法

支持 GFM 管道表格：

| 功能   | 快捷键    | 说明      |
| ---- | ------ | ------- |
| 加粗   | Ctrl+B | 选中文本后加粗 |
| 斜体   | Ctrl+I | 选中文本后倾斜 |
| 代码   | Ctrl+E | 行内代码    |
| 链接   | Ctrl+K | 插入链接    |
| 源码模式 | Ctrl+/ | 一键切换    |

### 如何导出

从菜单选择「文件 → 导出」，可导出 PDF 或 HTML。PDF 使用静默打印管线，不需要额外安装组件。

## 主题

内置三套主题：

1. **github-light**：默认浅色主题，适合白天写作。
2. **github-dark**：暗色主题，适合夜间环境。
   * 对比度符合无障碍标准。
   * 代码高亮同步切换。
3. **paper-serif**：衬线字体主题，模拟纸面阅读体验。

## 隐私说明

* 编辑器不联网上传你的文档。
* 崩溃上报默认关闭，可在设置中开启。
* 文件监听只作用于你打开的目录。
