## 2. 设计定位与原则

**定位**：对标 Typora 的"纸面感"写作工具 —— 界面是书桌，文档是主角。

1. **内容优先**：chrome（外壳）永远比正文低一级对比度；写作时可用"沉浸模式"把侧栏、工具栏全部收起。
2. **安静的中性色 + 单一强调色**：中性暖灰墨色体系，全局只有一个 accent（琥珀/品牌蓝二选一，见 §4），强调色只出现在"激活/焦点/主操作"。
3. **零装饰**：不用渐变、3D、复杂阴影；层级用"灰度差 + 1px 边框 + 极浅阴影"表达（Swiss 风格检索结论）。
4. **键盘优先**：所有操作可达、焦点环永远可见（UX 准则库 High 级：Focus States / Keyboard Navigation）。

## 3. 设计系统（Design Tokens）

### 3.1 色彩 —— 双层 token 架构（解决 D2）

- **chrome 层**：`--ui-*`，作用于外壳（侧栏/标签页/工具栏/状态栏/弹窗）。
- **doc 层**：`--md-*`，保留现有命名，作用于 Milkdown/CodeMirror 文档区。
- 两层独立取值，主题文件同时定义两组；`scripts/theme-check.mjs` 扩展校验双层 token 完整性。

#### 默认浅色（基于检索结果 "Notes & Writing App" 调校）

| Token            | 值        | 用途                           |
| ---------------- | --------- | ------------------------------ |
| `--ui-bg`        | `#FFFBEB` | 外壳底（暖纸色）               |
| `--ui-surface`   | `#FFFFFF` | 卡片/弹窗/输入框               |
| `--ui-fg`        | `#0F172A` | 外壳正文                       |
| `--ui-fg-muted`  | `#475569` | 次要文字（对 #FFFBEB ≥ 4.5:1） |
| `--ui-border`    | `#EEEDED` | 分隔线                         |
| `--ui-accent`    | `#D97706` | 激活标签下划线、焦点环、主按钮 |
| `--ui-accent-fg` | `#000000` | accent 上的文字                |
| `--ui-danger`    | `#DC2626` | 破坏性操作                     |

> `#D97706` 琥珀 accent 呼应"暖纸"底色；`paper-serif` 主题天然适配。`github-light/dark` 主题可保持 GitHub 冷灰底，仅共享同一 token 命名。

#### 暗色（`github-dark` 为基线扩展）

`--ui-bg:#0d1117` / `--ui-surface:#161b22` / `--ui-fg:#e6edf3` / `--ui-fg-muted:#8b949e` / `--ui-border:#30363d` / `--ui-accent:#f59e0b`（暗色下提亮一档以满足 4.5:1）。

### 3.2 字体

| 用途       | 字体                                           | 说明                                                               |
| ---------- | ---------------------------------------------- | ------------------------------------------------------------------ |
| UI（外壳） | Inter（本地回退 `system-ui`）                  | 检索结论：Swiss/中性、适合工具类 UI；Electron 内置回退，不联网加载 |
| 文档正文   | 随主题（现有 Georgia 衬线 / sans 切换保留）    | `paper-serif` 用衬线维持"纸面感"                                   |
| 代码       | JetBrains Mono → 回退 `ui-monospace, Consolas` | 源码模式与行内代码                                                 |

字号阶梯（4px 基）：12（辅助）/ 13（UI 默认）/ 15–16（文档正文，可在设置中调）/ 20（H2 预览）…；行高：UI 1.45，正文 1.6–1.75。

### 3.3 空间 / 圆角 / 阴影 / 动效（解决 D5、D6）

- 间距：8px 网格，`4/8/12/16/24/32`；面板内边距统一 `12px`，弹窗 `24px`。
- 圆角：`--radius-sm:4px`（按钮/输入）、`--radius-md:8px`（弹窗/卡片）、`--radius-lg:12px`（设置面板）。
- 阴影：仅两级 —— `--shadow-1`（悬浮工具条、弹层）、`--shadow-2`（模态弹窗）。
- 动效 token：`--dur-fast:150ms`、`--dur:200ms`、`--ease:cubic-bezier(.2,0,0,1)`；仅过渡 `opacity/transform/color`；全局声明 `@media (prefers-reduced-motion: reduce)` 关闭位移类动画。

## 4. 信息架构与布局重设计

### 4.1 目标布局

```
┌────────────────────────────────────────────────┐
│ 标题栏（frameless 自绘）：mac交通灯 / Win 最小化等 │
├──────────┬─────────────────────────────────────┤
│ 侧栏     │  标签页条（脏标记● + 关闭×，溢出滚动）  │
│ ┌──────┐ ├─────────────────────────────────────┤
│ │文件树│  │  格式工具栏（可选显示，滚动时隐藏）      │
│ ├──────┤ ├─────────────────────────────────────┤
│ │大纲  │  │                                     │
│ └──────┘  │        文档编辑区（WYSIWYG/源码）      │
│           │                                     │
├──────────┴─────────────────────────────────────┤
│ 状态栏：左侧状态·字数 ｜ 右侧 模式切换·沉浸·设置    │
└────────────────────────────────────────────────┘
```

- 侧栏改为 **双标签（文件 / 大纲）**，复用现有 `FileTree` 与 `OutlinePanel`，解决两面板并存问题；宽度可拖拽，双击分隔线复位。
- 新增 **沉浸模式**（快捷键 `Ctrl+Shift+P` 候选）：隐藏侧栏+标签条+工具栏，仅留文档与状态栏，鼠标移到边缘滑出。
- 空状态：无文档时文档区显示居中引导（"打开文件夹 / 新建文档"两个主操作），替代空白。

### 4.2 组件改造清单

| 组件                                      | 改造点                                                                                                                                                | 优先级 |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |

## 5. 无障碍与质量红线（ui-ux-pro-max 准则库）

1. 对比度：正文 ≥ 7:1，UI 文字与次要文字 ≥ 4.5:1（`#475569` on `#FFFBEB` ≈ 7.4:1 ✓）。
2. 焦点：`:focus-visible` 2px `--ui-accent` 环，永不 `outline:none` 裸移除；弹窗打开焦点困住（focus trap）+ 关闭归还焦点。
3. 图标一律 SVG + `aria-hidden`，交互图标带 `aria-label`；快捷键提示进 `title` 与 tooltip。
4. 键盘：Tab 顺序与视觉一致；工具栏支持 ←/→ 组内导航。
5. 尊重 `prefers-reduced-motion`。
6. `pnpm theme:check` 扩展为：双层 token 完整性 + 对比度自动计算（token 十六进制解析算 WCAG ratio）。
