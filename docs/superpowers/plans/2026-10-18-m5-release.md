# M5 发布打磨 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成发布能力：三平台安装包、签名/公证配置（无证书降级标注）、electron-updater 自动更新、性能验收与文档/落地页收口。

**Architecture:** 打包统一走 electron-builder 26（配置文件 `electron-builder.yml`）；更新走 electron-updater + GitHub Releases（generic provider，main 进程内闭环，渲染进程零 Node）；签名/公证全部经环境变量注入，无证书时干净降级并在发布说明标注；性能验收复用 `scripts/measure-startup.mjs` 采样口径（development.md 7 节：M5 以私有工作集为准）。

**Tech Stack:** Electron 44 / electron-builder 26 / electron-updater 6 / Vitest / GitHub Actions。

**Spec:** `TODO.md` M5 节、`architecture.md` 2.1（updater 属主进程）/ 5 节性能预算、`AGENTS.md` 铁律与门禁。

## Global Constraints

- 每个任务提交前 `pnpm lint && pnpm typecheck && pnpm test` 全绿；涉及 e2e 加跑 `pnpm e2e`。
- 渲染进程禁止 Node/fs；新 IPC 必须走 `electron/shared/channels.ts` 白名单 + preload 窄接口。
- `contextIsolation: true` / `nodeIntegration: false` / `sandbox: true` 不回退。
- 性能口径：安装包（下载体积）≤150MB · 安装后 ≤400MB · 冷启动（第二次及以后）<3s · 空文档常驻内存 ≤300MB（私有工作集口径）。
- 无签名证书时：配置读环境变量，缺失则跳过签名，`RELEASE.md` 标注 "unsigned build"。
- 提交信息英文祈使句 + scope。
- 自动更新必须仅在打包产物中启用（`app.isPackaged` 且无 `MD_EDITOR_DISABLE_UPDATER`）。

### Task 5: Release CI（tag 触发 publish）

**Files:**

- Create: `.github/workflows/release.yml`

**Interfaces:**

- Consumes: Task 1 yml、Task 2 env 约定、Task 3 updater（GitHub Releases 即更新源）。
- Produces: tag `v*` push → 三平台 matrix `pnpm build:app && pnpm exec electron-builder --publish always`，secrets 按 Task 2 注入；无 secrets 时仍出未签名产物并照常发布。

```yaml
name: Release
on:
  push:
    tags: ['v*']
jobs:
  release:
    strategy:
      fail-fast: false
      matrix:
        os: [ubuntu-latest, windows-latest, macos-latest]
    runs-on: ${{ matrix.os }}
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
        with: { version: 11.25.0 }
      - uses: actions/setup-node@v4
        with: { node-version: 24, cache: pnpm }
      - run: pnpm install --frozen-lockfile
      - run: pnpm build:app
      - run: pnpm exec electron-builder --publish always
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          CSC_LINK: ${{ secrets.CSC_LINK }}
          CSC_KEY_PASSWORD: ${{ secrets.CSC_KEY_PASSWORD }}
          APPLE_ID: ${{ secrets.APPLE_ID }}
          APPLE_APP_SPECIFIC_PASSWORD: ${{ secrets.APPLE_APP_SPECIFIC_PASSWORD }}
          APPLE_TEAM_ID: ${{ secrets.APPLE_TEAM_ID }}
```

- [ ] Step 1: 写 workflow；用 `actionlint`（或至少 YAML 语法校验）确认无误。
- [ ] Step 2: Commit `feat(ci): add tag-triggered release workflow`
