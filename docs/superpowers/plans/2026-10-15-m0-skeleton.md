**Goal:** 交付 md-editor 的最小可运行闭环——打开 `.md` → 所见即所得编辑 → `Ctrl+S` 原子保存 → 外部修改自动重载，并产出 M0 要求的两个技术 Spike 结论。

**Architecture:** pnpm workspace 承载 `src-tauri`（Rust 壳）+ 5 个前端包。`md-bridge` 用 remark/unified 产出 mdast（纯函数、本轮只落 `parseMarkdown`）；`editor` 包装 Milkdown/ProseMirror 并把编辑结果经 300ms 防抖收敛回 Buffer；`app` 持有 `MdDocument`（Buffer 唯一事实源）与工作台外壳；Rust 侧提供 `doc_read` / `doc_write`（原子写 + 写入凭证）与 `watch_file`（自身写入抑制）。

**Tech Stack:** Tauri 2.12.4（Rust 2021）+ React 18.3.1 + TypeScript 5.9.3 + Vite 8.3.4 + Milkdown 7.22.3 + remark 11 + Zustand 5 + Vitest 5.0.4 + Playwright 1.64.1 + ESLint 9 + pnpm 11

**执行顺序（2026-10-15 调整）：** 两个 Spike 前置到 Task 5–6（紧跟 Task 4），先拿架构结论再写主链路；Task 0 改为只读环境探明，不安装任何东西。

**Spec:** `TODO.md`（M0 段）· `architecture.md`（2.x / 3.x / ADR-1..6）· `component-api.md`（1.1 / 1.2 / 3 / 4.1）· `development.md`（2 / 3 / 4 / 5 / 6）· `DESIGN.md`（2.x）· `AGENTS.md`

## Global Constraints

- 唯一事实源：Markdown Buffer 是权威，PM Doc 只是投影；渲染模式键入允许 PM Doc 短暂领先，但必须在 300ms 防抖窗口内收敛回 Buffer（`architecture.md` 3.1）。
- 文件级往返保真：零编辑保存必须写回原始字节（`architecture.md` 3.3），因此 `MdDocument` 必须持有打开时的原始 base64 字节。
- 不引入第二套 Markdown 解析器/编辑内核：解析统一 remark/unified，编辑内核统一 ProseMirror/Milkdown，源码模式只允许 CodeMirror 6（`AGENTS.md` 铁律 3）。
- `packages/md-bridge` 是纯函数包，禁止依赖 UI/IO，覆盖率必须 100%（`development.md` 3、`AGENTS.md` 铁律 1）。
- 包依赖方向只允许向下：`app → editor/export/theming → md-bridge`（`development.md` 3）。
- TypeScript strict，禁止 `any`（`development.md` 4）。
- Rust：非测试代码禁止 `unwrap`/`expect`，错误处理用 `thiserror`，`cargo clippy -- -D warnings` 必须通过（`development.md` 4）。
- 主题 id 固定为 `github-light` / `github-dark` / `paper-serif`；编辑模式取值固定为 `wysiwyg` / `source`（`AGENTS.md` 速查表）。
- 版本口径：长图与 docx 导出 = v1.1，Wiki 双链 = v2；M0 一律不实现（`TODO.md`、`AGENTS.md`）。
- 提交信息使用英文祈使句 + scope，例如 `feat(app): add document model`（`development.md` 4）。
- 视觉 token 只能来自 `DESIGN.md` 2.x，禁止散落魔法数字。
- 环境版本地板：Node >= 20、pnpm >= 9；Windows 需 WebView2（本机已装 155.0.4283.45）。
- **零安装约束（用户 2026-10-15 指定）**：不安装任何系统级工具，只用现有环境；因此 Rust 相关任务默认只能在 CI 验证。

- [ ] **Step 4: 最小实现**

```ts
import type { Root } from 'mdast'
import remarkParse from 'remark-parse'
import { unified } from 'unified'

/** md-bridge 的 mdast 根节点类型别名，避免上层直接依赖 mdast 包。 */
export type MdastRoot = Root

/**
 * 把 Markdown 文本解析为 mdast。
 * 纯函数：无缓存、无 IO，同一输入恒等输出同一结构。
 */
export function parseMarkdown(text: string): MdastRoot {
  return unified().use(remarkParse).parse(text)
}
```

```ts
/** 只依赖 CSSStyleDeclaration 的一小部分能力，便于在 node 环境下测试。 */

  'github-light': 'light',
  'github-dark': 'dark',
  'paper-serif': 'light',
}

export function applyTheme(root: ThemeRoot, themeId: ThemeId): void {
  const tokens = themeTokens[APPEARANCE[themeId]]
  for (const [name, value] of Object.entries(tokens)) {
    root.style.setProperty(name, value)
  }
```

`packages/editor/src/sync.ts`:

```ts
export interface MarkdownSyncOptions {
  /** 默认 300ms，与 architecture.md 3.2 的防抖窗口一致。 */
  delayMs?: number
  serialize(): string
  onFlush(markdown: string): void
}

export interface MarkdownSync {
  schedule(): void
  flushNow(): void
  dispose(): void
  readonly pending: boolean
}

export function createMarkdownSync(options: MarkdownSyncOptions): MarkdownSync {
  const delayMs = options.delayMs ?? 300
  let timer: ReturnType<typeof setTimeout> | null = null
  let pending = false

  const clearTimer = () => {
    if (timer !== null) {
      clearTimeout(timer)
      timer = null
    }
  }

  const flush = () => {
    clearTimer()
    if (!pending) return
    pending = false
    options.onFlush(options.serialize())
  }

  return {
    schedule() {
      pending = true
      clearTimer()
      timer = setTimeout(flush, delayMs)
    },
    flushNow() {
      flush()
    },
    dispose() {
      clearTimer()
      pending = false
    },
    get pending() {
      return pending
    },
  }
}
```

```js
    called = true
  }

  window.print = original
  return called

await browser.close()

const header = bytes.subarray(0, 4).toString('latin1')

  chromiumVersion: engine,
  windowPrintCallable,
  silentPdfBytes: info.size,
  silentPdfHeader: header,
```

```tsx
// SPIKE: 一次性验证 Milkdown(PM) 与 CodeMirror 6 的互通成本，结论落地后整目录可删。
import { defaultKeymap, history as cmHistory, historyKeymap } from '@codemirror/commands'
import { markdown as cmMarkdown } from '@codemirror/lang-markdown'
import { EditorState } from '@codemirror/state'
import { EditorView, keymap } from '@codemirror/view'
import { defaultValueCtx, Editor, rootCtx } from '@milkdown/kit/core'
import { history } from '@milkdown/kit/plugin/history'
import { listener, listenerCtx } from '@milkdown/kit/plugin/listener'
import { commonmark } from '@milkdown/kit/preset/commonmark'
import { gfm } from '@milkdown/kit/preset/gfm'
import { getMarkdown } from '@milkdown/kit/utils'
import { Milkdown, MilkdownProvider, useEditor } from '@milkdown/react'
import { parseMarkdown } from '@md-editor/md-bridge'
import { useEffect, useRef, useState } from 'react'

const INITIAL = `# 标题

普通段落，含 *斜体*、**粗体**、\`inline\` 与 [链接](https://example.com)。

- 列表项一
- 列表项二

| 列 A | 列 B |
| --- | --- |
| 1 | 2 |

\`\`\`ts
const a = 1
\`\`\`
`

function nodeTypes(markdown: string): string {
  return parseMarkdown(markdown)
    .children.map((node) => node.type)
    .join('>')
}

function describeDiff(before: string, after: string): string {
  if (before === after) return 'byte-equal'
  if (nodeTypes(before) === nodeTypes(after)) return 'text-only-diff'
  return `node-diff: ${nodeTypes(before)} => ${nodeTypes(after)}`
}

function SpikeInner() {
  const container = useRef<HTMLDivElement | null>(null)
  const view = useRef<EditorView | null>(null)
  const api = useRef<() => string>(() => INITIAL)
  const [text, setText] = useState(INITIAL)
  const [mode, setMode] = useState<'wysiwyg' | 'source'>('wysiwyg')
  const [report, setReport] = useState<string[]>([])

  const { get } = useEditor(
    (root) =>
      Editor.make()
        .config((ctx) => {
          ctx.set(rootCtx, root)
          ctx.set(defaultValueCtx, text)
          ctx.get(listenerCtx).markdownUpdated(() => undefined)
        })
        .use(commonmark)
        .use(gfm)
        .use(history)
        .use(listener),
    [],
  )

  useEffect(() => {
    api.current = () => {
      const editor = get()
      return editor ? editor.action(getMarkdown()) : text
    }
  }, [get, text])

  useEffect(() => {
    if (mode !== 'source' || container.current === null) return
    const instance = new EditorView({
      state: EditorState.create({
        doc: text,
        extensions: [cmHistory(), keymap.of([...defaultKeymap, ...historyKeymap]), cmMarkdown()],
      }),
      parent: container.current,
    })
    view.current = instance
    return () => {
      instance.destroy()
      view.current = null
    }
  }, [mode, text])

  const push = (line: string) => setReport((lines) => [...lines, `${lines.length + 1}. ${line}`])

  const toggle = () => {
    if (mode === 'wysiwyg') {
      const next = api.current()
      push(`PM -> CM：${describeDiff(text, next)}`)
      setText(next)
      setMode('source')
      return
    }
    const next = view.current?.state.doc.toString() ?? text
    const selection = view.current?.state.selection.main
    const caret = selection ? `${selection.from}-${selection.to}` : 'n/a'
    push(`CM -> PM：${describeDiff(text, next)}；光标 ${caret}（切换后按 PM 起点处理，预期丢失）`)
    setText(next)
    setMode('wysiwyg')
  }

  return (
    <main style={{ fontFamily: 'system-ui, sans-serif', padding: 16 }}>
      <button type="button" onClick={toggle}>
        切换到{mode === 'wysiwyg' ? '源码' : '渲染'}模式
      </button>
      <button type="button" onClick={() => setReport([])}>
        清空报告
      </button>
      <span style={{ marginLeft: 12, color: '#57606a' }}>当前：{mode}</span>
      <ol style={{ color: '#57606a', fontSize: 13 }}>
        {report.map((line) => (
          <li key={line}>{line}</li>
        ))}
      </ol>
      {mode === 'wysiwyg' ? (
        <Milkdown />
      ) : (
        <div ref={container} style={{ border: '1px solid #d0d7de' }} />
      )}
    </main>
  )
}

export function Spike() {
  return (
    <MilkdownProvider>
      <SpikeInner />
    </MilkdownProvider>
  )
}
```

```ts
const encoder = new TextEncoder()
const decoder = new TextDecoder()

export function encodeUtf8Base64(text: string): string {
  const bytes = encoder.encode(text)
  let binary = ''
  for (const byte of bytes) {
    binary += String.fromCharCode(byte)
  }
  return btoa(binary)
}

export function decodeUtf8Base64(base64: string): string {
  const binary = atob(base64)
  const bytes = Uint8Array.from(binary, (char) => char.charCodeAt(0))
  return decoder.decode(bytes)
}
```

```ts
import { encodeUtf8Base64 } from '../base64'

export interface MdDocumentInit {
  id: string
  path: string | null
  text: string
  /** 打开文件时的原始字节（base64），用于零编辑保存的字节级保真。 */
  originalBytesBase64: string
  eol: 'lf' | 'crlf'
  hasBom: boolean
}

export interface TextRange {
  from: number
  to: number
}

/**
 * Markdown Buffer 的唯一事实源。
 * 不变式：text 始终可序列化为 mdast/PM Doc；PM Doc 只是它的投影。
 */
export class MdDocument {
  private currentText: string
  private originalBytes: string
  private dirty = false

  constructor(private readonly init: MdDocumentInit) {
    this.currentText = init.text
    this.originalBytes = init.originalBytesBase64
  }

  get id(): string {
    return this.init.id
  }

  get path(): string | null {
    return this.init.path
  }

  get eol(): 'lf' | 'crlf' {
    return this.init.eol
  }

  get hasBom(): boolean {
    return this.init.hasBom
  }

  get text(): string {
    return this.currentText
  }

  get isDirty(): boolean {
    return this.dirty
  }

  /** 渲染模式键入防抖收敛：PM Doc -> Markdown -> Buffer。 */
  applyEditorMarkdown(markdown: string): void {
    if (markdown === this.currentText) return
    this.currentText = markdown
    this.dirty = true
  }

  /** 查找替换等操作直接改 Buffer；PM 侧同步由 Caller 负责。 */
  replaceText(range: TextRange, replacement: string): void {
    const next =
      this.currentText.slice(0, range.from) + replacement + this.currentText.slice(range.to)
    if (next === this.currentText) return
    this.currentText = next
    this.dirty = true
  }

  /** 零编辑时返回原始字节，避免任何序列化规范化污染文件。 */
  bytesForSave(): string {
    return this.dirty ? encodeUtf8Base64(this.currentText) : this.originalBytes
  }

  markSaved(): void {
    if (this.dirty) {
      this.originalBytes = encodeUtf8Base64(this.currentText)
    }
    this.dirty = false
  }

  /** 外部修改且 Buffer 干净时的自动重载路径。 */
  setExternalText(text: string, originalBytesBase64: string): void {
    this.currentText = text
    this.originalBytes = originalBytesBase64
    this.dirty = false
  }
}
```

```ts
import { invoke } from '@tauri-apps/api/core'
import { listen } from '@tauri-apps/api/event'

export interface FileContent {
  base64: string
  text: string
  eol: 'lf' | 'crlf'
  hasBom: boolean
}

export interface WriteCredential {
  path: string
  size: number
  mtimeMs: number
  writtenAtMs: number
}

export interface Ipc {
  readFile(path: string): Promise<FileContent>
  writeFile(path: string, bytesBase64: string): Promise<WriteCredential>
  watchFile(path: string): Promise<void>
  onExternalModified(handler: (path: string) => void): Promise<() => void>
}

export function createTauriIpc(): Ipc {
  return {
    readFile: (path) => invoke<FileContent>('doc_read', { path }),
    writeFile: (path, bytesBase64) => invoke<WriteCredential>('doc_write', { path, bytesBase64 }),
    watchFile: (path) => invoke<void>('watch_file', { path }),
    async onExternalModified(handler) {
      return listen<string>('fs:external-modified', (event) => handler(event.payload))
    },
  }
}

interface TestWindow {
  __MD_IPC__?: Ipc
}

export function injectedIpc(): Ipc | null {
  return (window as TestWindow).__MD_IPC__ ?? null
}

export function isTestMode(): boolean {
  return injectedIpc() !== null
}

let cached: Ipc | null = null

export function getIpc(): Ipc {
  if (cached === null) {
    cached = injectedIpc() ?? createTauriIpc()
  }
  return cached
}
```

```rust
use crate::error::IoError;
use base64::{engine::general_purpose::STANDARD, Engine as _};
use serde::Serialize;
use std::path::{Path, PathBuf};
use std::time::{SystemTime, UNIX_EPOCH};

#[derive(Debug, Clone, PartialEq, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct FileContent {
    pub base64: String,
    pub text: String,
    pub eol: String,
    pub has_bom: bool,
}

#[derive(Debug, Clone, PartialEq, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct WriteCredential {
    pub path: String,
    pub size: u64,
    pub mtime_ms: u64,
    pub written_at_ms: u64,
}

pub fn now_ms() -> u64 {
    SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .map(|elapsed| elapsed.as_millis() as u64)
        .unwrap_or(0)
}

fn mtime_ms(metadata: &std::fs::Metadata) -> Result<u64, IoError> {
    let modified = metadata.modified()?;
    let elapsed = modified
        .duration_since(UNIX_EPOCH)
        .map_err(|_| IoError::Clock)?;
    Ok(elapsed.as_millis() as u64)
}

pub fn read_file(path: &Path) -> Result<FileContent, IoError> {
    let bytes = std::fs::read(path)?;
    let has_bom = bytes.starts_with(&[0xEF, 0xBB, 0xBF]);
    let body = if has_bom { &bytes[3..] } else { &bytes[..] };
    let text = String::from_utf8(body.to_vec()).map_err(|_| IoError::InvalidUtf8 {
        path: path.display().to_string(),
    })?;
    let eol = if text.contains("\r\n") { "crlf" } else { "lf" };
    Ok(FileContent {
        base64: STANDARD.encode(&bytes),
        text,
        eol: eol.to_string(),
        has_bom,
    })
}

fn tmp_path(path: &Path) -> PathBuf {
    let mut raw = path.as_os_str().to_os_string();
    raw.push(".tmp");
    PathBuf::from(raw)
}

/// 原子写：写 .tmp -> fsync -> rename；Unix 额外 fsync 父目录。
pub fn write_atomic(path: &Path, bytes: &[u8]) -> Result<WriteCredential, IoError> {
    let parent = path
        .parent()
        .ok_or_else(|| IoError::NoParent {
            path: path.display().to_string(),
        })?;
    let tmp = tmp_path(path);

    let result = (|| -> Result<(), IoError> {
        {
            let mut file = std::fs::File::create(&tmp)?;
            std::io::Write::write_all(&mut file, bytes)?;
            file.sync_all()?;
        }
        std::fs::rename(&tmp, path)?;
        #[cfg(unix)]
        std::fs::File::open(parent)?.sync_all()?;
        #[cfg(not(unix))]
        let _ = parent;
        Ok(())
    })();

    if result.is_err() {
        let _ = std::fs::remove_file(&tmp);
    }
    result?;

    let metadata = std::fs::metadata(path)?;
    Ok(WriteCredential {
        path: path.display().to_string(),
        size: metadata.len(),
        mtime_ms: mtime_ms(&metadata)?,
        written_at_ms: now_ms(),
    })
}
```

```rust
use crate::fs_io::WriteCredential;

/// 自身写入抑制：优先用 (path, size, mtime) 三元组精确匹配；
/// 500ms 时间窗只作为兜底（见 architecture.md 2.1）。
pub fn should_suppress(
    credential: &WriteCredential,
    event_path: &str,
    size: u64,
    mtime_ms: u64,
    now_ms: u64,
) -> bool {
    if credential.path != event_path {
        return false;
    }
    if credential.size == size && credential.mtime_ms == mtime_ms {
        return true;
    }
    now_ms.saturating_sub(credential.written_at_ms) <= 500
}
```

```rust
use crate::error::IoError;
use crate::fs_io::now_ms;
use crate::state::AppState;
use notify::{RecursiveMode, Watcher};
use std::path::{Path, PathBuf};
use tauri::{Emitter, Manager};

/// 只监听当前打开的文件；打开新文件时替换旧 watcher。
/// M3 会升级为工作区级增量监听（TODO.md M3）。
pub fn watch_single_file(
    app: tauri::AppHandle,
    path: &Path,
) -> Result<notify::RecommendedWatcher, IoError> {
    let target = PathBuf::from(path);
    let handler_target = target.clone();
    let mut watcher = notify::recommended_watcher(move |result: notify::Result<notify::Event>| {
        let Ok(event) = result else {
            return;
        };
        if !event.paths.iter().any(|candidate| candidate == &handler_target) {
            return;
        }
        let Ok(metadata) = std::fs::metadata(&handler_target) else {
            return;
        };
        let Some(path_string) = handler_target.to_str().map(str::to_string) else {
            return;
        };
        let event_mtime = metadata
            .modified()
            .ok()
            .and_then(|time| time.duration_since(std::time::UNIX_EPOCH).ok())
            .map(|elapsed| elapsed.as_millis() as u64)
            .unwrap_or(0);
        let state = app.state::<AppState>();
        let suppressed = state.last_write().is_some_and(|credential| {
            should_suppress(&credential, &path_string, metadata.len(), event_mtime, now_ms())
        });
        if !suppressed {
            let _ = app.emit("fs:external-modified", path_string);
        }
    })
    .map_err(|error| IoError::Watch(error.to_string()))?;

    watcher
        .watch(&target, RecursiveMode::NonRecursive)
        .map_err(|error| IoError::Watch(error.to_string()))?;

    Ok(watcher)
}
```

> `unwrap_or(0)` 不是 `unwrap`：取不到 mtime 时降级到 500ms 兜底分支，不构成 panic 风险。

```tsx
import { listener, listenerCtx } from '@milkdown/kit/plugin/listener'
import { commonmark } from '@milkdown/kit/preset/commonmark'
import { gfm } from '@milkdown/kit/preset/gfm'
import { getMarkdown } from '@milkdown/kit/utils'
import { Milkdown, MilkdownProvider, useEditor } from '@milkdown/react'
import { useEffect, useMemo, useRef } from 'react'
import { createMarkdownSync } from './sync'

export interface MarkdownEditorApi {
  getMarkdown(): string
  flushNow(): void
}

export interface MilkdownEditorProps {
  docId: string
  initialMarkdown: string
  onMarkdownChange(markdown: string): void
  onEditorReady?(api: MarkdownEditorApi): void
}

function MilkdownInner(props: MilkdownEditorProps) {
  const api = useRef<MarkdownEditorApi | null>(null)
  const { docId, initialMarkdown, onMarkdownChange, onEditorReady } = props

  const sync = useMemo(
    () =>
      createMarkdownSync({
        delayMs: 300,
        serialize: () => api.current?.getMarkdown() ?? initialMarkdown,
        onFlush: (markdown) => onMarkdownChange(markdown),
      }),
    [initialMarkdown, onMarkdownChange],
  )

  useEffect(() => () => sync.dispose(), [sync])

  const { get } = useEditor(
    (root) =>
      Editor.make()
        .config((ctx) => {
          ctx.set(rootCtx, root)
          ctx.set(defaultValueCtx, initialMarkdown)
          ctx.get(listenerCtx).markdownUpdated(() => {
            sync.schedule()
          })
        })
        .use(commonmark)
        .use(gfm)
        .use(history)
        .use(listener),
    [docId],
  )

  useEffect(() => {
    const handle: MarkdownEditorApi = {
      getMarkdown: () => {
        const editor = get()
        return editor ? editor.action(getMarkdown()) : initialMarkdown
      },
      flushNow: () => sync.flushNow(),
    }
    api.current = handle
    onEditorReady?.(handle)
  }, [get, initialMarkdown, onEditorReady, sync])

  return <Milkdown />
}

export function MilkdownEditor(props: MilkdownEditorProps) {
  return (
    <MilkdownProvider>
      <MilkdownInner {...props} />
    </MilkdownProvider>
  )
}
```

```tsx
import { useAppStore } from './state/appStore'

const E2E_PATH = 'C:/e2e/doc.md'

function nextDocId(path: string): string {
  return `${path}#${Date.now()}`
}

export function App() {
  const doc = useAppStore((state) => state.doc)
  const setDoc = useAppStore((state) => state.setDoc)
  const externalNotice = useAppStore((state) => state.externalNotice)
  const setExternalNotice = useAppStore((state) => state.setExternalNotice)
  const [reloadToken, setReloadToken] = useState(0)
  const [status, setStatus] = useState('未打开文件')
  const editorApi = useRef<MarkdownEditorApi | null>(null)

  const toDocument = useCallback(
    (path: string, content: FileContent): MdDocument =>
      new MdDocument({
        id: nextDocId(path),
        path,
        text: content.text,
        originalBytesBase64: content.base64,
        eol: content.eol,
        hasBom: content.hasBom,
      }),
    [],
  )

  const openFile = useCallback(
    async (path: string) => {
      const content = await getIpc().readFile(path)
      await getIpc().watchFile(path)
      setDoc(toDocument(path, content))
      setExternalNotice(null)
      setStatus(`已打开 ${path}`)
    },
    [setDoc, setExternalNotice, toDocument],
  )

  const save = useCallback(async () => {
    const current = useAppStore.getState().doc
    if (current === null || current.path === null) return
    editorApi.current?.flushNow()
    const credential = await getIpc().writeFile(current.path, current.bytesForSave())
    current.markSaved()
    setStatus(`已保存 ${current.path} @ ${credential.mtimeMs}`)
  }, [])

  useEffect(() => {
    if (isTestMode()) {
      void openFile(E2E_PATH)
    }
  }, [openFile])

  useEffect(() => {
    const unsubscribe = getIpc().onExternalModified(async (path) => {
      const current = useAppStore.getState().doc
      if (current === null || current.path !== path) return
      if (current.isDirty) {
        setExternalNotice('文件已被外部修改，请手动另存以免覆盖')
        return
      }
      const content = await getIpc().readFile(path)
      current.setExternalText(content.text, content.base64)
      setReloadToken((token) => token + 1)
      setExternalNotice(null)
      setStatus('已自动重载外部修改')
    })
    return () => {
      void unsubscribe.then((off) => off())
    }
  }, [setExternalNotice])

  useEffect(() => {
    const onKeyDown = (event: KeyboardEvent) => {
      if (!(event.ctrlKey || event.metaKey) || event.key.toLowerCase() !== 's') return
      event.preventDefault()
      void save()
    }
    window.addEventListener('keydown', onKeyDown)
    return () => window.removeEventListener('keydown', onKeyDown)
  }, [save])

  return (
    <main className="workspace">
      <header className="chrome">
        <button
          type="button"
          onClick={async () => {
            const selected = await open({
              multiple: false,
              filters: [{ name: 'Markdown', extensions: ['md', 'markdown'] }],
            })
            if (typeof selected === 'string') await openFile(selected)
          }}
        >
          打开文件
        </button>
        <button type="button" onClick={() => void save()}>
          保存
        </button>
        <span className="status">
          {doc?.isDirty ? '未保存 · ' : ''}
          {status}
        </span>
      </header>
      {externalNotice !== null ? <p className="notice">{externalNotice}</p> : null}
      <section className="editor-host">
        {doc === null ? (
          <p className="placeholder">打开一个 Markdown 文件开始写作</p>
        ) : (
          <MilkdownEditor
            key={`${doc.id}-${reloadToken}`}
            docId={doc.id}
            initialMarkdown={doc.text}
            onMarkdownChange={(markdown) => doc.applyEditorMarkdown(markdown)}
            onEditorReady={(api) => {
              editorApi.current = api
            }}
          />
        )}
      </section>
    </main>
  )
}
```
